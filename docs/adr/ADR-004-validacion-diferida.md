# ADR-004: diferir la validación externa sin inventar evidencia

**Estado:** aceptado · **Fecha:** 2026-09-02

No existe aún una muestra accesible para cuestionarios o pruebas moderadas. Se permite avanzar con la base técnica y un incremento demostrable usando hipótesis documentadas. Antes de pagos reales, piloto público o expansión de alcance se retomarán entrevistas y pruebas con jugadores, organizadores y complejos.

El cuestionario descubrirá requisitos adicionales, no convertirá el producto en software a medida. Los hallazgos se clasificarán como problema validado, ajuste al MVP, candidato posterior o necesidad particular descartada.
